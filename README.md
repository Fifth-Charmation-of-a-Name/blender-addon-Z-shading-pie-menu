# Z Shading Pie Menu

A Blender add-on (3.6+) that adds a pie menu to the 3D Viewport for quickly switching viewport shading and render engine.

## Usage

1. Install the add-on via **Edit > Preferences > Add-ons > Install**, then enable it.
2. In the 3D Viewport, press **Z** (default) to open the pie menu.
3. Pick an option:
   - **Wireframe**, **Solid**, **Material Preview**
   - **Rendered** with **Cycles**, **Workbench**, **Eevee**, or **Eevee (Ray Tracing)**

## Settings

The shortcut key can be changed to Z, Q, W, E, or R in the add-on preferences.

## Notes

- Choosing a Rendered option also sets the scene's render engine.
- Selecting the mode that is already active does nothing.
